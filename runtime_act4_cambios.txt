1. CONTRATO DEL JSON (lo que el runtime lee y el compilador escribe)
-------------------------------------------------------------
Toda la lectura esta en UNA funcion (snake_cargar_config, L466). Si el JSON final
usa otros nombres, solo se cambia esa funcion. Las claves se aceptan en mayusculas
o minusculas; las banderas aceptan true/false, 1/0 o "ON"/"OFF". TODO es opcional.

  "default_level": "BABY",            (por defecto BABY)
  "level_order": ["BABY","ENTUSIASTA","NYAN_CAT"],   (opcional)
  "level_up_score": 50,               (opcional; 0 = sin avance automatico)
  "levels": {
     "BABY":       {"tick":150, "poison":"OFF", "shield":false,
                    "clouds":false, "head":"NORMAL", "tail":"NORMAL"},
     "ENTUSIASTA": {"tick":100, "poison":"SUBTRACT", "shield":true, ...},
     "NYAN_CAT":   {"tick":75, "poison":"SUBTRACT", "shield":true,
                    "clouds":true, "head":"CAT", "tail":"RAINBOW"}
  },
  "shapes": {
     "SNAKE_BODY":   {"form":"CIRCULAR", "color":"#00FF00"},
     "POISON_FRUIT": {"color":"#8A2BE2", "penalty":10},
     "CLOUD":        {"color":"#DDDDDD", "count":6},
     "SHIELD_FRUIT": {"color":"#FFD700", "duration":8}
  }

Notas:
- tick va en MILISEGUNDOS (el lexer actual no lee decimales como 0.15).
- poison: OFF | SUBTRACT | KILL.   head: NORMAL | CAT.   tail: NORMAL | RAINBOW.
- form: RECTANGLE (por defecto) | CIRCULAR | TRIANGULAR.
- Opcional por nivel: "shield_duration" sobreescribe el DURATION de SHIELD_FRUIT
  (el compilador lo escribe si el .brick trae SHIELD_DURATION dentro de un LEVEL).
- Si el JSON no trae "levels", o trae uno solo (el BABY que el compilador agrega a un
  snake.brick viejo), el juego es el Snake original: tick 150, sin veneno, nubes,
  escudo, panel de niveles ni teclas 1-3. El modo multinivel exige 2 o mas niveles.
- "shapes" de Tetris/Snake original (PIXEL -> lista de matrices) no se toca:
  solo se leen las entradas SNAKE_BODY, POISON_FRUIT, CLOUD y SHIELD_FRUIT
  cuando son diccionarios.
- El compilador (seccion 8) escribe exactamente estas claves: el JSON compilado desde
  snake_evolved.brick coincide con snake_evolved_ejemplo.json en todas las claves ACT4.

2. CAMBIOS COMUNES (afectan el ciclo del juego)  L27-62, L81-84, L155-170, L202
-------------------------------------------------------------
- Constantes por defecto (SNAKE_NIVEL_DEFECTO = el Snake original, L29) y tres
  funciones auxiliares: _minusculas (L41), _es_si (L49), _aclarar (L56).
- paso_loop (L81): el ciclo corre cada 25 ms en Snake (50 ms en Tetris, igual
  que antes). Asi un TICK de 75 ms o 100 ms es exacto. Los TICK deben ser
  multiplos de 25 ms (150, 125, 100, 75, 50); otro valor se redondea hacia arriba
  (el compilador avisa con una "Advertencia" si el TICK no es multiplo de 25).
- tolerancia_tick (L84): evita que la suma de decimales (0.025 x 6 = 0.1499999)
  retrase un tick. Es 0 en Tetris para no alterar su temporizacion.
- game_loop (L155): llama a snake_actualizar_estado() (L169) antes de dibujar.
- teclas 1/2/3 en manejar_input_gui (L202).

3. INTEGRANTE 2 - LOGICA  (L401-435 y L450-716)
-------------------------------------------------------------
snake_cargar_config (L466)
  Que hace: lee del JSON niveles, estilo del cuerpo y entidades, con
  valores por defecto, y deja listo el estado (NORMAL, sin nubes, etc.).

snake_aplicar_nivel (L530)
  Activa un nivel: mezcla su configuracion con los defaults, fija
  velocidad_gravedad = tick/1000, borra lo del nivel anterior y genera lo
  que el nuevo nivel activa (nubes, venenos, escudo). Se llama una vez al
  iniciar (despues de ON_START, porque ahi aparece la serpiente) y al
  cambiar de nivel. Se conservan serpiente y puntaje.

snake_saltar_nivel / snake_revisar_subida_nivel (L572, L579)
  Teclas 1-3 (D2) y avance automatico: pasar del nivel i al i+1 exige
  level_up_score x (i+1) puntos. Tras un salto manual hace falta ganar
  puntos nuevos para volver a subir solo (ver seccion 9, cambio R1).

MANEJADOR DE ESTADOS - snake_actualizar_estado (L590)
  Tres estados: NORMAL, INVULNERABLE, GAME_OVER. Corre en cada vuelta del
  game_loop: NORMAL -> INVULNERABLE al comer el escudo; INVULNERABLE ->
  NORMAL cuando se cumple el tiempo; cualquiera -> GAME_OVER si el juego
  termino. Tambien hace reaparecer la fruta de escudo y revisa el avance.

TEMPORIZADOR DEL POWER-UP - snake_activar_escudo (L709)
  Al comer el escudo guarda invulnerable_hasta = time.time() + DURATION.
  snake_es_invulnerable() (L605) compara contra time.time(). Como usa segundos
  reales, la duracion NO depende del tick (dura n segundos igual en Baby
  que en Nyan Cat). La fruta reaparece 6 s despues de terminar el efecto.

COLISION CON NUBES - snake_colision_nube (L687)
  Se evalua cuando la cabeza entra en una celda con nube:
    invulnerable          -> se ignora
    puntaje > 0           -> puntaje = 0 y la serpiente SIGUE VIVA
    puntaje == 0          -> GAME OVER inmediato
  Las nubes son fijas; se generan al iniciar el nivel Nyan Cat.

FRUTA VENENOSA - snake_comer_veneno (L699)
  SUBTRACT resta "penalty" sin bajar de 0. KILL termina el juego. Con
  invulnerabilidad no tiene efecto (D3). La fruta consumida se repone.

snake_mover_jugador (L409)  (funcion existente, modificada)
  - Paredes: siempre matan, tambien con escudo (D3).
  - Cuerpo propio: solo mata si NO es invulnerable.
  - Despues de insertar la cabeza llama a snake_procesar_entidades (L675: nubes,
    venenos, escudo). Lo demas (comer, crecer) igual que el original.

APARICION (D4) - snake_celda_libre (L631)
  Elige al azar una celda libre: nunca sobre la serpiente, la comida u otra
  entidad; las nubes ademas a mas de 3 celdas de la cabeza. snake_spawn_comida
  (L401) tambien evita las entidades.

4. INTEGRANTE 3 - DIBUJO  (L205/L238 y L717-874)
-------------------------------------------------------------
Regla: el bloque de dibujo SOLO LEE el estado (serpiente_cuerpo, nubes,
venenos, escudo, cfg_nivel, estado_snake). No modifica variables de juego.

snake_dibujar_todo (L736)  - llamado desde dibujar() (L238)
  Dibuja comida, nubes, venenos, escudo, serpiente y actualiza el panel.

snake_dibujar_forma (L789)  firma: (x, y, forma, color, direccion)
  RECTANGLE -> dibujar_celda (original); CIRCULAR -> create_oval;
  TRIANGULAR -> create_polygon con la punta hacia donde avanza el segmento.

snake_dibujar_serpiente (L750)
  Dibuja de la cola a la cabeza. Cola RAINBOW: color del segmento i =
  SNAKE_COLORES_ARCOIRIS[(i + fase) % 6]; "fase" cambia con el tiempo y
  hace que los colores parezcan correr. Parpadeo blanco ~6 veces por
  segundo mientras es invulnerable. Sin FORM ni niveles usa los colores
  originales (cabeza #00FF00, cuerpo #33CC33).
  (Los segmentos se dibujan de la cola a la cabeza: el orden de los items del
  Canvas cambia respecto al original, pero los rectangulos y colores son los mismos.)

snake_dibujar_cabeza_gato (L813)
  Circulo + 2 orejas triangulares + 2 ojos con pupila + nariz + bigotes,
  con 9 primitivas del Canvas. Escala con taman_celda (_esc).

snake_dibujar_nube / veneno / escudo (L834, L842, L853)
  Nube: 3 ovalos solapados. Veneno: circulo morado con calavera simple.
  Escudo: estrella dorada de 5 puntas.

snake_actualizar_panel (L866)
  Muestra "NIVEL <nombre>" y "ESCUDO n.n s" (cuenta regresiva). Solo existe
  cuando el JSON trae "levels" con 2 o mas niveles; con el Snake original el
  panel no cambia.

Sintaxis nueva del .brick (ver snake_evolved.brick):
  DEFINE SHAPE SNAKE_BODY:   FORM: CIRCULAR | TRIANGULAR | RECTANGLE   COLOR: #RRGGBB   END
  DEFINE SHAPE POISON_FRUIT: COLOR: #...   PENALTY: n  [COUNT: n]  END
  DEFINE SHAPE CLOUD:        COLOR: #...   COUNT: n     END
  DEFINE SHAPE SHIELD_FRUIT: COLOR: #...   DURATION: n  END     (segundos)
  DEFINE LEVELS:
    DEFAULT_LEVEL: BABY            (opcional)
    LEVEL_UP_SCORE: 50             (opcional; 0 = sin avance automatico)
    LEVEL BABY:       TICK: 150
    LEVEL ENTUSIASTA: TICK: 100  POISON: SUBTRACT  SHIELD: ON
    LEVEL NYAN_CAT:   TICK: 75   POISON: SUBTRACT  SHIELD: ON  CLOUDS: ON  HEAD: CAT  TAIL: RAINBOW
                      [SHIELD_DURATION: n]
  END
  Un LEVEL termina cuando empieza otro LEVEL o llega el END del bloque.
  Lo que un LEVEL no escribe queda como en el Snake original (TICK 150, POISON OFF,
  SHIELD OFF, CLOUDS OFF, HEAD NORMAL, TAIL NORMAL).
